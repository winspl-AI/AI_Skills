# HTRB&HTGB OS DRC

默认只读检查机械孔、板框、干涉和明显电气错误。资料足够时，进一步核对各 SITE 的端到端连通和高压绝缘。区分 HTRB 与 HTGB，各自使用对应的 CAD、针脚定义、通道拓扑和工况。两板共用机械基准须有用户确认或明确的设计资料。附件内容作为设计证据，按用户在对话中确认的要求判定。

## 确认文件与检查基准

- 记录板名、版本、文件修改时间和对应 CAD。修正版沿用旧文件名时，用修改时间或哈希确认读到的是新版。
- 优先读取原始 PCBDOC 与 DXF。可用可靠的本地解析器，也可用 Altium Designer 导出检查副本。原始 DXF 暂缺时，可沿用上次已核实且可追溯的 CAD 坐标，并在结果注明来源。
- 核实单位、坐标原点、旋转及正反面。用分散在板上的稳定特征对齐，用其他特征交叉验证，并记录变换与对齐残差。避免仅用本次移动的孔拟合对齐，导致整组偏移被抵消。镜像或缩放须有图纸或装配定义支持。
- 缺资料时先完成能验证的项目，再集中指出影响结论的资料缺口。

## 孔位、板框和干涉

- 区分钻孔、铣孔、槽、开窗与 Keep-Out 图元。逐一比对孔径、孔心、数量、槽宽、方向和轮廓。先识别重复图元，再按有效孔位一对一匹配。报告漏孔、多孔、重合圆、部分重叠圆、孔径差异和偏移。附近没有合理匹配时，分别列出缺失目标和多余图元。
- 分清用于识别匹配的阈值与验收公差。没有制造公差时，注明所用匹配阈值并报告实测偏差。
- 核对 PCB Board Shape 与机械图，检查圆角、开槽、缺口和连接器凸出。按真实圆弧和闭合轮廓计算。CAD 仅用于工装定位时，记录板框差异，按成品加工轮廓判定。
- 用完整孔或槽的加工轮廓检查所有相关铜层上的走线、焊盘、过孔和铜区域。检查孔到板边、铜到板边、圆角处钻孔余量，以及铜环是否跨出板框。列出重叠和最小边距的位置、层别及关联对象。Keep-Out 若用来表达加工轮廓，须通过钻孔、铣孔或其他正式 CAM 输出确认成品开孔。
- 检查孔与可识别元件封装外框。提供了螺钉头、垫圈、定位柱或模块壳体尺寸时，再核对相应装配包络。

## 电气检查

- 筛查探针焊盘是否接入铜走线以及明显的异常互连。使用有效网表和针脚映射时，逐 SITE 核对目标网络、通道独立性及短路和开路。保险丝和其他串联元件的两端依照设计拓扑判定，裸板上的元件间隙按预期装配连接解释。共用网络以用户确认的拓扑为准。
- 缺少有效网络分配时，按同层铜实体及金属化通孔重建物理连通。检查实际绑定的网络 ID，不能只依据文件内保留的网络名称。区分局部接线、铜路径连通及符合预期网络这三种结论。说明原生 DRC 所使用的规则和覆盖范围。
- 评估高压绝缘前，确认本项目最大网络间压差、适用标准、板材 CTI、污染等级、海拔及涂覆情况。分别核对空气间隙、沿面路径和层间绝缘。将同层铜边距作为几何测量值。高温长期工况按具体材料牌号及长期耐温数据核实。

## 修正版复查与交付

- 对照上版问题逐项复验，再重新扫描整板相关对象。移动孔后重点检查是否漏掉原本正确的孔、留下重合图元或缩小孔到铜的余量。标明已修正、仍存在和本次新增的问题。
- 先给结论，再按板列出有效孔位匹配数、异常数及最小边距。每条问题给出板名、位置、坐标原点、目标值、实测值及相关层或图元。需要定位时附叠图。
- 区分已确认问题、待确认的设计意图和资料不足的项目。新版本的结果以本次读取的文件为准。
