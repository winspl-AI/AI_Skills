# 图片逐张验收清单

## A. 内容准确性
- [ ] 标题与 Markdown 原始标题一致
- [ ] 图片只对应一个章节，无跨章内容
- [ ] 核心观点与原文一致
- [ ] 关键公式、变量、单位、数值和测试条件正确
- [ ] 流程、箭头方向和步骤顺序正确
- [ ] 没有遗漏本章必要的工程逻辑
- [ ] 没有虚构数据、标准、厂商参数或实验结果
- [ ] 示意数据/曲线已明确标记为示意或 Example

## B. 视觉一致性
- [ ] 使用已确认的蓝白高信息密度工程信息图风格
- [ ] 正文标题左对齐，字号、字体层级统一
- [ ] 标题栏、卡片、箭头、Takeaway 与视觉母版一致
- [ ] 主体图像与当前章节主题相关
- [ ] 文字可读，无严重乱码、遮挡、重叠或裁切
- [ ] 正文图没有误用文章总标题或封面式构图
- [ ] 底部 Takeaway 只总结当前章节

## C. 文件检查
- [ ] 独立生成，不是拼图或总览图裁切
- [ ] 一张图对应一个计划项
- [ ] PNG 格式
- [ ] 封面实际尺寸 2350×1000 px（2.35:1）
- [ ] 正文/导语/总结实际尺寸 1573×1000 px（约1.573:1）
- [ ] 文件名与原始章节标题对应
- [ ] 正式交付目录不含草稿、失败图、重复图

## D. 最终交付检查
- [ ] 已生成全部计划图片
- [ ] 验收通过数量等于任务清单总数
- [ ] 目录结构正确
- [ ] 验收清单已更新
- [ ] ZIP 文件存在且可正常打开
- [ ] ZIP 内图片数量和文件名正确
- [ ] ZIP 不含临时图、失败图或拼图
